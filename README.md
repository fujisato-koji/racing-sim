# Apex Atlas

（リポジトリ名と配信の URL は racing-sim のままです。2026-10-24 にゲームの名前を Apex Atlas に決めました。）

ブラウザで遊べる three.js のレースゲームです。
車の動きは、タイヤの摩擦、サスペンション、エンジンから車輪までの駆動系、空気抵抗を計算して決めています。

遊ぶ：<https://fujisato-koji.github.io/racing-sim/>

## English

Apex Atlas is a browser racing game built with three.js. Tire friction, suspension, the drivetrain from engine to wheels, and aerodynamics are all simulated. The game itself is in English.

Play: <https://fujisato-koji.github.io/racing-sim/> (keyboard, gamepad, or a phone held in landscape and tilted to steer)

- 20 real circuits in four groups (Grand Prix, Technical, Street, Oval) plus 3 original tracks, chosen on a 3D globe. Track shapes come from OpenStreetMap and the surrounding terrain from real elevation data. Each track has its own light, weather and colors.
- Race against AI drivers, or run time attack laps against a ghost of your best lap with telemetry.
- Six preset cars and full tuning of dimensions, suspension, tires, engine, gearbox, differentials, aerodynamics and driver aids.
- Data credits: track shapes and nearby buildings © OpenStreetMap contributors (ODbL 1.0); terrain from Terrain Tiles (3DEP, SRTM and GMTED2010 data courtesy of the U.S. Geological Survey; ETOPO1 from NOAA; EU-DEM produced using Copernicus data and information funded by the European Union; © Environment Agency copyright and/or database right 2015, all rights reserved; © Commonwealth of Australia (Geoscience Australia) 2017); globe land outlines from Natural Earth (public domain). Details are in the Japanese sections below.

## 操作（キーボード）

| キー | 操作 |
|---|---|
| ← → または A D | ハンドル |
| ↑ または W | アクセル |
| ↓ または S | ブレーキ（止まりかけで押し続けると後退に入る） |
| C | 視点の切り替え（後方、運転席） |
| M | バックミラーの表示 |
| N | 全体の地図の表示 |
| R | 車をコースに戻す |
| V | 音を消す、戻す |
| E / Q | 手動変速で上げる、下げる |
| Esc | 一時停止 |

メニューもキーボードで選べます。↑↓ でコースや車を選び、←→ でコースの種類を切り替え、Enter で次へ、Esc で戻ります。一時停止と結果の画面では、↑↓ か ←→ でボタンを選んで Enter で押します。

変速は自動と手動を選べます（タイトルか一時停止の画面）。手動でも、下げると回りすぎるときは受け付けません。

ハンドルは、キーを押している時間で少しずつ切れます。いっぱいまでの時間は止まっているとき 0.3 秒、150 km/h で約 1 秒です。短く押したときは小さく切れるように、押した時間に曲線をかけています（短く押して向きを直し、押し続けて曲がる）。切れる速さは、タイトルか一時停止の画面の Keyboard steering speed（50〜200%）で変えられます。

横滑り防止（ESC）は、車が切れ角から見込める以上に回ったとき（後ろが流れたとき）だけ外側の前輪にブレーキをかけます。見込みのヨーレートは切れ角から幾何学的に決まる値を摩擦の上限で抑えたもので、ハンドルを戻した直後は 0.4 秒かけて下げます。

## 操作（ゲームパッド）

左スティックでハンドル、右トリガーでアクセル、左トリガーでブレーキです（押し込んだ量で効きます）。RB で上げる、LB で下げる、Y で視点、START で一時停止、BACK で車を戻します。

## 操作（スマホ）

- 横向きの画面で遊びます。Android は最初のタップで全画面にして横向きに固定します。iPhone は向きを固定できないので、縦向きのままなら画面全体を 90° 回して描きます（スマホを左に倒して持つ）。
- スマホをハンドルのように左右へ回すと切れます。スタートの瞬間の持ち方が中央で、「中央」ボタンで合わせ直せます。
- 中央付近ほど効きを鈍くしてあり、速いほど強く鈍くします。手のぶれで車がふらつかないようにするためです（人が 0.25 s 遅れて修正する模擬で、100 km/h の横揺れが 0.6 g から 0.04 g に減った。`test/tilt-wobble.ts`）。いっぱいに切る傾き（初期値 40°）と中央付近の鈍さは、一時停止の画面で変えられます。
- 右下がアクセル、左下がブレーキです。上のボタンで一時停止、視点、戻す、中央、音を操作します。
- iPhone では、最初のタップのあとに傾きセンサーの許可を求められます。許可しないときや傾きセンサーの無い端末では、◀ ▶ のボタンで切ります。

画面下のハンドルの絵と、運転席のハンドルは「実際のタイヤの切れ角 × ステアリングギア比」で回ります。いっぱいに切ると、実車と同じく片側 1〜1.8 回転します。

## メーター

実車のような回転計と速度計（針、赤い区域、目盛り）、ギア、変速の合図のランプ（5 つが順に灯り、レブリミットで点滅）、補助の警告灯（TCS、ABS、ESC）を出します。運転席視点では、同じメーターがハンドルの奥に見えます。

## 音

エンジン、タイヤの鳴き、砂利を踏む音、風切り、衝突の音を、Web Audio で合成しています（音声ファイルは使っていません）。

- エンジンは、回転数と気筒数から点火の周波数を出し、アクセル開度で音の濁りと大きさを変えます。
- 車種ごとに、気筒の並び（直列は均等、水平対向は 2 回の点火ごと、V 型は 4 回ごとの鼓動）、ターボ（過給の高い音、アクセルを戻したときの「プシュ」）、排気音の性格（静か、スポーツ、レース。レースは高回転でアクセルを戻すとはじける）を変えています。
- 近くを走る AI 車のエンジン音も、左右に振り分けて鳴らします。
- 衝突の音は、物理エンジンが返す接触の力の大きさで鳴らし分けます。

ブラウザは利用者の操作の前に音を出させないので、最初のクリックかタップで音が出るようになります。

## 画面の流れ

タイトル → コース → 車 → 詳細設定（飛ばせる） → レース → 結果

タイトル画面では、ロゴ（地球儀のまわりを回るレースラインと頂点の光）が出てきて、後ろで地球儀がゆっくり回ります。光る柱を押すと、そのコースを選んで次へ進みます。コースは地球儀の上から選べます。実在のサーキットの位置に光る柱が立ち、選ぶとその場所へ回り込んで、所在地、1 周の長さ、高低差、開場の年、紹介をカードに出します。

- コースは、オリジナル 3 つと実在のサーキット 20 です。オリジナルの試験場は周回のない自由走行で、ジャンプ台（10°、15°、20°）、砂利、砂地、岩場、コーン、タイヤの壁があります。
- 実在のサーキットは種類ごとに 5 つずつです。
  - 国際サーキット：鈴鹿、スパ・フランコルシャン、モンツァ、シルバーストン、富士スピードウェイ
  - テクニカル：ザントフォールト、ブランズハッチ、ハンガロリンク、筑波、ラグナ・セカ
  - 市街地：モナコ、マカオ（ギア）、マリーナベイ、バクー、アルバートパーク
  - オーバル：インディアナポリス、デイトナ、タラデガ、シャーロット、ブリストル（バンク付き）
- 車は代表的な車種を6つ用意しています（軽自動車、小型ハッチバック、FR スポーツ、4WD ラリー、MR スーパーカー、SUV）。値は車格の代表値を仮に置いたもので、特定の実車ではありません。
- 詳細設定では、寸法、質量と重心、サス、タイヤ、ステアリングギア比、エンジンのトルク曲線と気筒数、ギア比、駆動方式、デフ、空力、補助を変えられます。変えた車はブラウザの中に保存でき、JSON で書き出して読み込めます。
- 対戦相手は AI です。プレイヤーと同じ物理の車を、同じ3つの入力（ハンドル、アクセル、ブレーキ）で動かします。
- タイムアタックでは 1 台で周回します。コースに戻さずに走りきった周のうち最速の周を、車と設定ごとにブラウザへ残し、次からは半透明のゴーストとして一緒に走ります。走行中は最速の周との差を、一時停止と結果の画面ではテレメトリ（速さ、アクセルとブレーキ、差）を出します。

## 読み上げと実況

メニューとレースを英語で読み上げます（タイトルか一時停止の画面の Voice で、メニューと実況、メニューだけ、なしを選べます）。

- 声はブラウザの音声合成（Web Speech API）で、端末に入っている英語の声から選びます（イギリス英語の男性の声を優先）。Edge の Natural の声や Chrome の Google の声は、そのブラウザの会社の音声合成のサービスで読まれます。読むのはゲームの決まった文（コース名、車名、実況の言い回し、AI の名前）だけです。
- メニュー：画面の名前、種類、コース名と国、車名と馬力を読みます。一覧を速く動かしたときは、最後に選んだものだけを読みます。
- 実況：レースの始まり、スタート、順位の変化（1 秒変わらなければ）、前や後ろとの接近、先頭の入れ替わり、周のタイムと最速の周、ファイナルラップ、ゴール、スピン、コース外、接触、ジャンプ、速さ（200、250、300 km/h）を言います。しばらく黙っていたら前や後ろとの差を言います。タイムアタックでは、周の半ばの最速の周との差と、周のタイムを言います。
- 同じ話は間をあけ、ふつうの話は前の話から 2.5 秒あけます。大事な話（ファイナルラップ、ゴール）は読んでいる途中でも切り替えます。

## 物理の作り

| 部分 | 計算 |
|---|---|
| 車体 | 物理エンジン Rapier の剛体。質量、重心、慣性モーメントは諸元から与える |
| サス | 車輪ごとに円柱を地面へ当てて縮みを測り、ばね、ダンパー（縮みと伸びで別）、スタビライザー、底付きを計算する。ロールセンターを通る荷重移動も入れる |
| タイヤ | 滑り率と滑り角をそれぞれ最大摩擦の滑りで割って合成し、合成した向きに力を出す。緩和長で滑りを遅らせ、低速では減衰を足す。荷重が増えると摩擦係数が少し下がる |
| 駆動系 | エンジン、クラッチ、変速機、デフ（オープン、LSD、直結）、4WD のセンターデフを回転体と拘束でつなぎ、逐次インパルス法で解く。クラッチ、LSD、ブレーキ、転がり抵抗は上限付きの拘束で、上限を超えると滑る |
| 反トルク | 駆動系の角運動量の変化のうち、路面から来た分以外を車体に返す。空中でブレーキを踏むと機首が下がる |
| 空力 | 前後、左右、上下の抗力と、前後に分けたダウンフォース |
| 補助 | ABS、トラクションコントロール（前後と横を合わせた滑り、空中の空転、エンジンブレーキによる滑りを見る）、横滑り防止（回りすぎたら外側の前輪にブレーキ）、切れ角の補助（前輪が最大摩擦の滑り角を超えないように切れ角を抑える）。どれも切れる |

物理は 240 Hz の固定刻みで進め、描画は前後のステップの間を補間します。

## 見た目と描画

- 車体は、諸元の寸法から横から見た形（ボンネット、前後の窓、屋根、トランク）、上から見た形、断面を決めて一枚の面にしています。車輪の上はフェンダーの切り欠き、窓まわりはガラスと柱（A、B、C ピラー）を塗り分けます。車体の型（軽、ハッチバック、セダン、クーペ、SUV、ミッドシップ）で形が変わります。
- コースには、縁石（赤白。物理でも細かい段のある路面）、コンクリートの分離帯、白帯のコーン、タイヤバリア、木、観客席、ピットを置いています。まわり 30 km は遠景の地形（実在のコースは標高データ、作ったコースは雑音から作った山）で、遠くほど霞みます。
- 木は針葉樹、広葉樹、笠松、ヤシ、糸杉の 5 種類で、種類ごとに形の違う 3 本を、向き、大きさ、色味をずらして並べます。木は散らさず、森は密な塊にします。遠くの森は樹冠の面（でこぼこの緑の塊）で描き、道から見える帯と森の縁に 1 本ずつの木を並べます。畑の多いコース（シルバーストン、インディアナポリスなど）は、畑の境に並木を置きます。森の広さと樹冠の高さはテーマごとに決めています。
- コースごとに色のテーマがあります。時刻と天気（太陽の高さと向き、光の色、霞）、草と森の色、木の種類、建物の外壁、差し色を 1 つの雰囲気にまとめています（例：鈴鹿は秋の午後、スパは曇りの森、モナコは地中海の昼、マリーナベイは夕暮れ）。定義は `src/render/themes.ts` です。
- 空は上ほど濃い青で、太陽のまわりが明るく、同じ空を車の塗装やガラスに映しています。
- 描画の質は 自動、低、中、高 から選べます（タイトルか一時停止の画面）。自動のときは、フレームの時間を見て描く画素の数を減らしたり戻したりします。

### 路面

| 路面 | 最大摩擦の倍率 | 転がり抵抗係数 | 特徴 |
|---|---|---|---|
| アスファルト | 1.0 | 0.012 | 少し滑ったところで摩擦が最大になり、それ以上滑ると落ちる |
| 砂利 | 0.62 | 0.03 | 大きく滑ってから最大になり、滑っても落ちにくい。細かい凹凸 |
| 砂地 | 0.45 | 0.15 | 砂利よりさらに平らで、タイヤが沈む |
| 岩場 | 0.8 | 0.03 | 大きな凹凸と、乗り上げられる岩 |
| 草地 | 0.5 | 0.05 | 緩い凹凸 |

路面と車の数値は、調整を始めるための仮置きです。出典はありません。

## 実在のサーキットのデータ

- 形は OpenStreetMap（© OpenStreetMap contributors）から取りました。サーキットの区間をつないで公式の 1 周の長さに最も近い周回を選び、ピットロードの一方通行の向きからレースの向きとスタートの位置を決めています。取り込んだ周回の長さは、公式の長さとの差がおおむね 1% 以内です。
- 標高は、日本は国土地理院の標高 API、米国は NED 10 m、欧州は EU-DEM 25 m、そのほかは SRTM 30 m（OpenTopoData 経由）です。データが崖や建物の高さを拾うことがあるので、勾配（サーキット 18%、市街地 10%）と勾配の変わり目に上限を置いています。シンガポールとアルバートパークは、建物や木の高さが混ざるので平らにしました。
- 鈴鹿の立体交差は橋になり、オーバルは曲がりのきつさに合わせて路面が傾きます（デイトナ 31°、タラデガ 33° など）。
- 市街地は壁の外に街の建物を置いています。建物の形と並びは作り物で、実際の街並みではありません。
- コース幅は資料にあればその値、無ければ似たコースの値を仮に置いています。公式の長さ、向き、バンク角の出典は `tools/track-specs.md` にあります。
- `src/sim/tracks/*.json` は OpenStreetMap から作ったデータなので、Open Database License (ODbL) 1.0 で公開します（`src/sim/tracks/README.md`）。取り込み直すときは `npx tsx tools/fetch-tracks.ts [id ...]` です。
- 実在のコースのまわり 30 km の遠景の地形は、AWS の Terrain Tiles（https://registry.opendata.aws/terrain-tiles/ 、terrarium 形式、ズーム 11、2026-10-24 取得）から作りました。コースの中心から同心円の格子（半径 150 m から 30 km まで 64 段、角度 256 分割）の標高を `src/sim/scenery/*.json` に入れています。取り込み直すときは `npx tsx tools/fetch-scenery.ts [id ...]` です。Terrain Tiles の表示の決まり（https://github.com/tilezen/joerd/blob/master/docs/attribution.md ）に従い、使った地域に効く提供元を次のとおり表示します（ゲームの中ではコースを選ぶ画面の出典の行に出します）。
  - 3DEP, SRTM and GMTED2010 data courtesy of the U.S. Geological Survey
  - ETOPO1: U.S. National Oceanic and Atmospheric Administration
  - Produced using Copernicus data and information funded by the European Union - EU-DEM layers（ベルギー、イタリア、オランダ、ハンガリー、モナコ、アゼルバイジャン、イギリス）
  - © Environment Agency copyright and/or database right 2015. All rights reserved（イギリス）
  - © Commonwealth of Australia (Geoscience Australia) 2017（オーストラリア）
- コースのまわり（コースの外接の四角 + 120 m）の建物は、OpenStreetMap の建物の足元の形と高さ（height、無ければ階数 × 3.2 m）から作りました（`src/sim/buildings/*.json`、ODbL 1.0、2026-10-24 取得）。道の近くの建物にはぶつかります。取り込み直すときは `npx tsx tools/fetch-buildings.ts [id ...]` です。
- 遠景の植生の色、窓の並び、壁と屋根の色、コースの範囲より外の街の建物、作ったコースの山は作り物です。範囲より外の街の建物は高さと並びを乱数で置いたもので、実際の街並みではありません。
- コースを選ぶ画面の地球儀の陸の形は、Natural Earth の 1:110m の陸地（パブリックドメイン、https://github.com/nvkelso/natural-earth-vector の `geojson/ne_110m_land.geojson`、2026-10-24 取得）から作りました。作り直すときは `npx tsx tools/make-globe.ts <GeoJSON のパス>` です。各コースの所在地、開場の年、紹介文は `src/sim/tracks/places.ts` にあります。

## 開発

```bash
npm install
npm run dev       # 開発用サーバー
npm run build     # 型検査と配信物の生成（dist/）
npm run check     # 物理の検算（全プリセット）
npm run race      # AI だけでレースを走らせる（例: npm run race -- rally 2）
npm run skidpad   # 定常円旋回で横加速度の最大を測る
npm run feel      # キーボードの操作を再現して、横滑り角と前後の滑り角を測る（例: npm run feel -- mr-super）
npx tsx test/keyboard-tap.ts   # キーを短く押したとき、長く押したときの向きの変化、減速、ESC の働く時間を測る
npx tsx test/commentary.ts circuit 3   # AI に走らせたレースで、実況が言ったことを時刻と並べて出す（attack を足すとタイムアタック）
npm run map -- <出力先>  # コースを上から見た図を PNG に描く
```

`npm run check` は、画面なしで各プリセットを走らせ、次を確かめます。

- 止めておいた車が揺れ続けないこと
- 最高速が、駆動力と抵抗の釣り合いから出した見積りと 6% 以内で合うこと
- 0-100 km/h の加速時間が常識の範囲にあること
- 長い直線で向きが 1.5° 以上ずれないこと
- 100 km/h からの制動距離が、摩擦係数だけで決まる理想の 0.85〜1.5 倍に入ること
- 15° の坂でブレーキを踏んで 5 秒止まっていられること（ずれが 5 cm 未満）

`test/browser-smoke.ts`、`test/browser-jump.ts`、`test/browser-mobile.ts`（スマホを模した画面で、傾きとペダルを送る）は、手元の Edge を自動で操作して画面を撮る確認用の道具です（`npm run preview` を先に起動する）。

## 構成

```
src/
  sim/       物理（描画に依らず Node でも動く）
    vehicle.ts     車体、サス、タイヤ、空力、変速
    drivetrain.ts  エンジンから車輪までの拘束と解法
    tire.ts        タイヤの力
    surfaces.ts    路面の係数と凹凸
    params.ts      諸元の型、設定画面の項目、目安の計算
    presets.ts     代表車種
```
